# Designing Dashboards with AI

A HubForge playbook about building dashboards that help people act. The web playbook offers practical exercises; the PDF edition contains 27 pages.

## The DESIGN framework

1. **Decide:** Start with the decision the dashboard should support.
2. **Establish metrics:** Select metrics relevant to that decision.
3. **Structure the layout:** Organize the dashboard so readers can find what matters.
4. **Illustrate:** Choose suitable ways to present the data.
5. **Guard:** Check quality and protect trust in the dashboard.
6. **Nurture:** Learn from use and improve the dashboard.

## Topics

The playbook covers a five-second dashboard test, a worked example, a dashboard-design reference section, practical workshops, AI collaboration, conversation starters, and a launch check.
